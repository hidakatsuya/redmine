# ガント内部刷新の回帰テスト結果（2026-09-08）

[GANTT_TEST_PLAN.md](GANTT_TEST_PLAN.md) の G01–G20 を40ケースで実行した。
表示対象・行順・開閉・選択・クエリ保持の前後比較では回帰を検出していない。
ただし、ブラウザ印刷には旧実装にもある改ページ時の件名欠落があるため、全ケース成功とはしない。

## 今回の修正

- 短いチャートの下余白を二重に加算しない。折りたたんでも外枠の高さを維持する。
- `ProjectSection#row_count` と `Chart#row_count` で、全ViewModelを生成せず高さに必要な行数を取得する。
- 印刷時にはチャートの幅を文書の幅へ反映し、旧実装と同じブラウザの縮小処理が働くようにする。背景も印刷の行配置へ合わせる。
- 行数が上限とちょうど一致した場合も、旧実装と同じ警告を表示する。
- 曜日表示を正式名の先頭文字から、旧実装と同じ略称の先頭文字へ戻す。狭い目盛りで省略記号が曜日を隠す問題を修正する。
- 追加列の見出しを折り返さず表示し、短期間・低ズームでは外枠をチャート幅に収める。

PDF/PNGの描画実装は変更していない。画面と印刷の変更は旧実装の挙動に近づけるための修正。

この既存問題は今回修正していない。行単位の改ページと関連線を一緒に扱う印刷設計が別途必要。
